# 对白切分、字幕、降噪与拼接

在逐镜参考音频、最终视频字幕、局部噪声或多段 MP4 拼接任务中使用本参考。原则是先确定每一阶段的“音频事实源”，再做派生处理。

## 音频事实源

按阶段区分，不混用时间轴：

1. 锁定母带：决定完整台词及顺序。
2. 逐镜参考音频：决定提交给视频模型的内容和目标时长。
3. 最终采用视频的实际音轨：决定该镜字幕、缺词判断和最终听感。
4. 最终拼接音轨：决定切点是否有爆音、跳动或累计延迟。

`reference_audio` 不保证输出逐样本复制，因此第 2 项不能代替第 3 项。

## 跨镜语义切点

- 波形、RMS 和静音检测只定位“可能的停顿”，不能识别“要稳”之类的语义边界。
- 边界不确定时，围绕候选点按 0.05–0.20 秒步长导出多个短片段，让用户找出“完整包含前一句且尚未进入下一句”的最早版本。
- 用户确认时间 `T` 后，只保留一个边界：`shot N = [..., T]`，`shot N+1 = [T, ...]`。不要分别猜两个相邻时间。
- 为满足模型固定时长而补静音时，只在语义切片后补尾部；不要移动开头或重复边界附近样本。
- 保留母带和所有候选片段，正式文件名写明确认的边界或版本。

## 最终视频字幕校准

1. 从最终采用的无字幕视频提取实际音轨。
2. 用波形或静音检测找出发声段，再结合锁定台词判断每段语义。
3. 同一说话者连续两句若有明显停顿，优先拆成两条字幕；换人时前一条必须在后一人开口前消失。
4. 若模型输出缺少某句话，删除对应字幕并报告缺词；字幕不能替音轨“补说”。
5. 先锁定统一样式，再批量烧录。用户只要求改文字或时间时，不顺带改变颜色、字号、换行和位置。
6. 用关键时间点截图检查文字和样式，但音画同步结论仍需实际播放；抽帧不能替代听校。

## 噪声处理

先判断噪声位于哪里：

- 模型输出有噪声、参考音频干净：优先直接替换为参考音轨，并检查口型和字幕同步。
- 参考音频也有噪声：换轨无效，再做频谱降噪。
- 噪声只在局部：先制作全段轻度/较强 A/B 样片；用户选定基线后，只对明确时间范围加强处理，避免整段人声变闷或产生金属感。

所有降噪版本另存，不覆盖原音轨。交付时明确哪些是客观验证（时长、可解码、无削波），哪些仍需主观试听（残余嘶声、齿音、自然度）。

可用 FFmpeg 的 `afftdn`、`anlmdn`、`deesser`、`highpass`、`lowpass`，但参数应从温和设置开始。带 `enable='between(t,start,end)'` 的局部处理适合用户已经指出具体噪声时段的情况。

## 多段拼接与时间戳

分镜规格一致时，视频可优先流复制以避免再次损失画质。AAC 分段直接拼接可能出现 `Non-monotonic DTS`；不要忽略警告后直接称为最终成片。

常用修复策略是保留视频码流，仅统一重编码音轨并归零：

```powershell
ffmpeg -fflags +genpts -f concat -safe 0 -i shots.concat.txt `
  -map 0:v:0 -map 0:a:0 -c:v copy -c:a aac -b:a 192k `
  -af "aresample=async=1:first_pts=0" -movflags +faststart output.mp4
```

完成后检查：完整解码、总时长、分辨率、帧率、音轨、所有切点、首尾帧，以及最终实际播放。供应商常在标称时长外增加少量编码尾帧，最终时长以成片探测值为准。
